# Участие в разработке

[English version](CONTRIBUTING.en.md)

Репозиторий пока закрытый. Изменения принимаются владельцем. Этот файл фиксирует, как вести работу, чтобы история на GitHub оставалась понятной.

## Правила языка

- Пользовательские документы: либо полностью по-русски, либо полностью по-английски. Не смешивать языки в одном файле.
- Главная страница — [README.md](README.md) (русский). Английский текст — [README.en.md](README.en.md).
- Комментарии в коде — на английском.
- Описания релизов GitHub — на русском.

## Что входит в git

В репозиторий входят исходники `telegram_bridge`, хуки, тесты, публичные markdown-файлы, `.env.example`.

Не коммитить:

- `.env`, `.venv`
- внутренние заметки `_docs` и `_other`
- секреты, токены, `chat_id`

## Окружение

Python 3.11+, команда `python`. Зависимость: `mcp>=1.28,<2`.

```text
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe tests\run_hook_cases.py
```

Живые вызовы Telegram требуют заполненный `.env`. Токен в чаты и в git не копировать.

## Коммиты

Один коммит — одна законченная мысль. Сообщение описывает зачем изменение, а не список файлов. Автор коммита — владелец репозитория, без co-author Cursor.

После изменения поведения обновить [CHANGELOG.md](CHANGELOG.md) и при необходимости [CHANGELOG.en.md](CHANGELOG.en.md).

## Релизы

Тег вида `vX.Y.Z`. Текст релиза на русском: что появилось, что сломано, как обновиться. Подробности — в [CHANGELOG.md](CHANGELOG.md).
